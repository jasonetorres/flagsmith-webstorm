# Changelog

## 0.1.0

Initial Marketplace release of Flagsmith Feature Flags, an unofficial community plugin for JetBrains IDEs.

- Flags tab: browse, search, toggle, create, and edit feature flags against self-hosted or cloud Flagsmith.
- In-editor gutters, completion, and an unknown-flag inspection (with a create-flag quick fix) for JS/TS flag APIs.
- Editor action: Create Flagsmith Flag from Selection.
- Experiments tab: list experiments, inspect hypothesis, variants, metrics, and rollout, start / pause / complete an experiment, and show trait-based A/B results with a winner, lift, p-value, significance badge, and conversion bars.
- Settings under **Settings | Tools | Flagsmith**, with the Organisation API key stored in the IDE password safe.
